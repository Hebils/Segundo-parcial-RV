# AvesGO UAO
Juego web tipo Pokémon GO con A-Frame: aves del campus UAO (Guía Ilustrada 2023), mini quiz y enciclopedia. Funciona offline (service worker + A-Frame local).

## Publicar en GitHub Pages
1. Crea un repo y sube el contenido de esta carpeta (index.html, sw.js, vendor/).
2. Settings → Pages → Branch: `main` / root → Save.
3. Abre `https://TU-USUARIO.github.io/NOMBRE-REPO/` (HTTPS, necesario para cámara AR y modo offline).

## Cómo se juega (v2)
GPS + brújula + cámara. Las aves están ancladas en el mundo real: camina hacia ellas (radar abajo a la izquierda) y tócalas a menos de 25 m. "Modo prueba" funciona sin GPS (arrastra para mirar, ▲▼ para caminar).
Si ves la versión vieja, recarga con Ctrl+Shift+R o borra los datos del sitio.
